# Admin User Management Implementation Plan

## Context

**Current State:**
- Admin dashboard exists at `/api/v1/admin` with read-only user listing
- Users table has `is_admin` boolean flag for permissions
- Subscriptions table tracks tier (free/student/pro/team), status, billing info
- CASCADE deletes configured: deleting user removes all related data
- Auth middleware (`requireAdmin`) already protects admin routes
- Existing patterns: PATCH for updates, DELETE for removals in other routes

**Key Findings:**
1. Users have `is_admin` flag in database (migration 0005)
2. Subscriptions linked via `user_id` with CASCADE delete
3. Current `/admin/users` endpoint only lists users with basic info
4. No subscription data currently shown in admin dashboard
5. Account deletion pattern exists in `/account/delete` route
6. PATCH pattern used in `/account/me`, `/workspaces/:id`, etc.

**Database Schema:**
```sql
users: id, email, name, avatar_url, password_hash, is_admin, created_at
subscriptions: id, user_id, tier, status, stripe_customer_id, 
               billing_interval, current_period_start/end, price_usd
```

### Step 3: Create User Update Endpoint
**File:** `src/server/api/routes/admin.ts`

Add `PATCH /admin/users/:id` for editing:
```typescript
const UpdateUserSchema = z.object({
  name: z.string().min(1).max(255).optional(),
  is_admin: z.boolean().optional(),
  // Note: Don't allow email changes (auth identifier)
});

admin.patch("/users/:id", 
  zValidator("json", UpdateUserSchema),
  async (c) => {
    const userId = c.req.param("id");
    const updates = c.req.valid("json");
    const sql = getSql();
    
    // Prevent admin from removing their own admin status
    const currentAdmin = c.get("user");
    if (userId === currentAdmin.id && updates.is_admin === false) {
      return c.json({ 
        error: "forbidden", 
        message: "Cannot remove your own admin privileges" 
      }, 403);
    }
    
    // Build dynamic UPDATE
    const sets = [];
    if (updates.name !== undefined) sets.push(sql`name = ${updates.name}`);
    if (updates.is_admin !== undefined) sets.push(sql`is_admin = ${updates.is_admin}`);
    
    if (sets.length === 0) return c.json({ ok: true });
    
    const setClause = sets.reduce((acc, cur, i) => 
      i === 0 ? cur : sql`${acc}, ${cur}`
    );
    
    await sql`
      UPDATE users 
      SET ${setClause}, updated_at = now() 
      WHERE id = ${userId}
    `;
    
    return c.json({ ok: true });
  }
);
```

const UpdateSubscriptionSchema = z.object({
  tier: z.enum(["free", "student", "pro", "team"]),
  status: z.enum(["active", "cancelled", "past_due", "trialing"]).optional(),
});

admin.patch("/users/:id/subscription",
  zValidator("json", UpdateSubscriptionSchema),
  async (c) => {
    const userId = c.req.param("id");
    const { tier, status } = c.req.valid("json");
    const sql = getSql();
    
    // Check if subscription exists
    const existing = await sql`
      SELECT id FROM subscriptions WHERE user_id = ${userId}
    `;
    
    if (existing.length === 0) {
      // Create subscription if missing
      await sql`
        INSERT INTO subscriptions (user_id, tier, status)
        VALUES (${userId}, ${tier}, ${status || 'active'})
      `;
    } else {
      // Update existing
      const updates = [sql`tier = ${tier}`];
      if (status) updates.push(sql`status = ${status}`);
      
      const setClause = updates.reduce((acc, cur, i) => 
        i === 0 ? cur : sql`${acc}, ${cur}`
      );
      
      await sql`
        UPDATE subscriptions 
        SET ${setClause}, updated_at = now()
        WHERE user_id = ${userId}
      `;
    }
    
    return c.json({ ok: true });
  }
);
```

### Step 5: Create User Delete Endpoint

admin.delete("/users/:id", async (c) => {
  const userId = c.req.param("id");
  const sql = getSql();
  const currentAdmin = c.get("user");
  
  // Prevent self-deletion
  if (userId === currentAdmin.id) {
    return c.json({ 
      error: "forbidden", 
      message: "Cannot delete your own account" 
    }, 403);
  }
  
  // Check if user exists
  const user = await sql`
    SELECT id, email, is_admin FROM users WHERE id = ${userId}
  `;
  
  if (user.length === 0) {
    return c.json({ error: "not_found" }, 404);
  }
  
  // Warn if deleting another admin
  if (user[0].is_admin) {
    // Optional: require confirmation via query param
    const confirmed = c.req.query("confirm") === "true";
    if (!confirmed) {
      return c.json({
        error: "confirmation_required",
        message: "This is an admin user. Add ?confirm=true to proceed"
      }, 400);
    }
  }
  
  // Delete user (CASCADE handles related records)
  await sql`DELETE FROM users WHERE id = ${userId}`;
  
  return c.json({ 
    ok: true, 
    deleted_email: user[0].email 
  });
});
```

const BulkUpdateSchema = z.object({
  user_ids: z.array(z.string().uuid()),
  action: z.enum(["activate_subscription", "deactivate_subscription", "promote_to_admin"]),
});

admin.post("/users/bulk-update",
  zValidator("json", BulkUpdateSchema),
  async (c) => {
    const { user_ids, action } = c.req.valid("json");
    const sql = getSql();
    
    switch (action) {
      case "activate_subscription":
        await sql`
          UPDATE subscriptions 
          SET status = 'active', updated_at = now()
          WHERE user_id = ANY(${user_ids})
        `;
        break;
        
      case "deactivate_subscription":
        await sql`
          UPDATE subscriptions 
          SET status = 'cancelled', updated_at = now()
          WHERE user_id = ANY(${user_ids})
        `;
        break;
        
      case "promote_to_admin":
        await sql`
          UPDATE users 
          SET is_admin = true, updated_at = now()
          WHERE id = ANY(${user_ids})
        `;
        break;
    }
    
    return c.json({ ok: true, affected: user_ids.length });
  }
);
```

admin.get("/users/search", async (c) => {
  const sql = getSql();
  const query = c.req.query("q") || "";
  const tier = c.req.query("tier");
  const status = c.req.query("status");
  const is_admin = c.req.query("is_admin");
  
  let conditions = sql`1=1`;
  
  if (query) {
    conditions = sql`${conditions} AND (u.email ILIKE ${'%' + query + '%'} OR u.name ILIKE ${'%' + query + '%'})`;
  }
  
  if (tier) {
    conditions = sql`${conditions} AND s.tier = ${tier}`;
  }
  
  if (status) {
    conditions = sql`${conditions} AND s.status = ${status}`;
  }
  
  if (is_admin !== undefined) {
    conditions = sql`${conditions} AND u.is_admin = ${is_admin === 'true'}`;
  }
  
  const rows = await sql`
    SELECT u.*, s.tier, s.status AS subscription_status
    FROM users u
    LEFT JOIN subscriptions s ON s.user_id = u.id
    WHERE ${conditions}
    ORDER BY u.created_at DESC
    LIMIT 100
  `;
  
  return c.json({ items: rows });
});
```

## Security Considerations

1. **Self-Protection:** Prevent admin from removing own admin status or deleting own account
2. **Admin Confirmation:** Require explicit confirmation when deleting admin users
3. **Audit Logging:** Consider logging admin actions to `pipeline_logs` or separate audit table
4. **Rate Limiting:** Admin endpoints already protected by rate limits
5. **Email Immutability:** Don't allow changing user email (auth identifier)
6. **Password Security:** Don't expose password_hash in responses

## Edge Cases to Handle

1. User with no subscription (LEFT JOIN returns null)
2. Attempting to update non-existent user (404)
3. Bulk operations on mixed user types (some admin, some not)
4. Subscription status transitions (active → cancelled vs cancelled → active)
5. Deleting last admin user (prevent)
6. Unicode in user names (already handled by Postgres)

## Performance Notes

- All queries use indexes on `user_id`, `email`
- JOIN with subscriptions adds minimal overhead
- Consider pagination for search if >1000 users
- Usage history limited to 6 months (LIMIT 6 in query)
