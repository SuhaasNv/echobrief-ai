# EchoBrief Pricing & Subscription System — Implementation Plan

## Context

### What I Explored
- **Database structure**: Postgres with migrations, already has `workspaces` with `kind` column, `users` with `default_account_type`
- **API architecture**: Hono-based REST API with middleware (auth, workspace, rate-limit)
- **Feature gating**: Currently only workspace `kind` (`student`/`professional`) gates features like flashcards
- **Frontend**: React with TanStack Router/Query, API client with typed hooks
- **No existing usage tracking**: No `usage_log` or `subscriptions` tables yet
- **No Stripe integration**: Acknowledged — planning for future integration

### Key Findings
1. **Workspace-first architecture**: All data is scoped to workspaces; middleware already injects `workspaceId` and `workspaceKind`
2. **Existing feature gates**: `requireProfessionalWorkspace()` middleware already gates integrations, email generation, and action-item exports
3. **Cost tracking exists**: `pipeline_logs` table tracks AI costs per operation, but no rollup to user-level usage
4. **Clean separation**: Backend (Hono API) + Frontend (React) + Worker (BullMQ) architecture

### Architecture Pattern Identified
- Feature access currently controlled by:
  - **Backend**: Middleware checks workspace `kind` → returns 403 if unauthorized
  - **Frontend**: No feature gates yet — UI shows all features regardless of tier
- PRICING.md proposes a **tier model** (`Free`, `Student`, `Pro`, `Team`) that maps to workspace rules

#### 1.1 Create Migration `0008_subscriptions_and_usage.sql`

**Tables to create:**

```sql
-- Subscription tiers
CREATE TABLE IF NOT EXISTS public.subscriptions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES public.users(id) ON DELETE CASCADE,
  tier TEXT NOT NULL CHECK (tier IN ('free', 'student', 'pro', 'team')),
  status TEXT NOT NULL DEFAULT 'active' CHECK (status IN ('active', 'cancelled', 'past_due', 'trialing')),
  
  -- Stripe IDs (nullable until Stripe integration)
  stripe_customer_id TEXT UNIQUE,
  stripe_subscription_id TEXT UNIQUE,
  
  -- Billing period
  billing_interval TEXT CHECK (billing_interval IN ('monthly', 'annual')),
  current_period_start TIMESTAMPTZ,
  current_period_end TIMESTAMPTZ,
  
  -- Pricing
  price_usd NUMERIC(10, 2),
  
  -- .edu verification for student tier
  edu_email_verified BOOLEAN DEFAULT false,
  
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now(),
  
  UNIQUE (user_id) -- One active subscription per user
);

CREATE INDEX subscriptions_user_idx ON public.subscriptions(user_id);
CREATE INDEX subscriptions_stripe_customer_idx ON public.subscriptions(stripe_customer_id) WHERE stripe_customer_id IS NOT NULL;

-- Usage tracking (rollup per user per month)
CREATE TABLE IF NOT EXISTS public.usage_logs (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES public.users(id) ON DELETE CASCADE,
  workspace_id UUID REFERENCES public.workspaces(id) ON DELETE SET NULL,
  
  -- Usage period (e.g., '2026-05' for May 2026)
  period TEXT NOT NULL, -- format: YYYY-MM
  
  -- Usage metrics
  transcription_minutes INTEGER DEFAULT 0,
  ai_queries_count INTEGER DEFAULT 0,
  flashcards_generated INTEGER DEFAULT 0,
  
  -- Cost tracking
  total_cost_usd NUMERIC(10, 6) DEFAULT 0,
  
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now(),
  
  UNIQUE (user_id, workspace_id, period)
);

CREATE INDEX usage_logs_user_period_idx ON public.usage_logs(user_id, period DESC);
CREATE INDEX usage_logs_workspace_period_idx ON public.usage_logs(workspace_id, period DESC) WHERE workspace_id IS NOT NULL;

-- Trigger for updated_at
CREATE TRIGGER subscriptions_set_updated_at
  BEFORE UPDATE ON public.subscriptions
  FOR EACH ROW EXECUTE FUNCTION public.set_updated_at();

CREATE TRIGGER usage_logs_set_updated_at
  BEFORE UPDATE ON public.usage_logs
  FOR EACH ROW EXECUTE FUNCTION public.set_updated_at();
```
